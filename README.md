# Food Waste Pattern Analyzer

## Overview
An interactive R Shiny dashboard that analyzes food preparation,
consumption, and waste patterns.

## Features
- Track prepared, served, and consumed food quantities
- Calculate unserved food and plate waste
- Visualize waste patterns using charts
- Filter data by date and food item
- Display key performance indicators
- Download filtered data

## Technologies Used
- R
- Shiny
- ggplot2
- DT

## How to Run
1. Install R and RStudio.
2. Install required packages:

   install.packages(c("shiny", "ggplot2", "DT"))

3. Open `app.R` in RStudio.
4. Click **Run App**.
